# Build Your First Recruitment Dashboard in Power BI

A beginner-friendly tutorial for building a recruitment dashboard in Power BI using an Excel file as the data source.

In this tutorial, we will learn how to import data, create basic DAX measures, build different types of visualizations, add slicers, and format a dashboard.

## What you will learn

By the end of this tutorial, you will be able to:

- Import an Excel file into Power BI.
- Create basic DAX measures for recruitment KPIs.
- Create KPI cards and different types of charts.
- Add a slicer to filter dashboard data.
- Format and customize a dashboard page.

## Prerequisites

- Power BI Desktop
- Basic familiarity with Power BI
